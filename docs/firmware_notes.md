# Firmware notes
The revised sketches preserve the original sensors, boards, pin assignments, OLED address, MQTT libraries and nominal 2/3-second intervals. They remove hardcoded credentials and identifiers, use configurable topics, label elapsed time correctly, and avoid publishing invalid DHT readings. The original ESP32 code used an indefinite connection wait and did not poll MQTT; this adaptation calls poll and attempts reconnection. Both revisions still use blocking connection retry loops, so sampling is interrupted while disconnected. Neither implements independent FreeRTOS tasks, guaranteed delivery, TLS, or occupancy counting. The revised code requires local compilation and physical validation.
